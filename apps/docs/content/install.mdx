---
title: Install
description: Install @irogane/kaji with npm or bun.
---

```bash
npm install @irogane/kaji
```

or with bun:

```bash
bun add @irogane/kaji
```

Kaji has zero runtime dependencies. It accepts any
[Standard Schema](https://standardschema.dev)-compatible validator for
capability input, but does not require or bundle one. The
[getting started](/docs/getting-started) guide uses [Zod](https://zod.dev)
as an example; install it separately if you use it:

```bash
npm install zod
```

## Version policy

`0.x` releases are pre-1.0. Pin an exact version in production and review
the changelog before upgrading.
